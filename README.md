Котировки облигаций Мосбиржи

Раз в 30 минут в торговые часы забирает данные с публичного API Мосбиржи (ISS), считает доходность по фактическим денежным потокам — с учётом НДФЛ и комиссии брокера — и складывает результат в quotes.json и quotes.md.

Токены и пароли не нужны: ISS отдаёт данные без авторизации.

Настройка (примерно 10 минут)
Создайте на GitHub публичный репозиторий, например bonds-quotes. Публичный — обязательно: Actions бесплатны только для публичных, и только из публичного я смогу читать файл.
Загрузите в него три файла, сохранив структуру:
   fetch_quotes.py
   watchlist.txt
   .github/workflows/quotes.yml

Проще всего через кнопку Add file → Upload files. Папку .github/workflows веб-интерфейс создаст сам, если при создании файла указать полный путь .github/workflows/quotes.yml.

Откройте вкладку Actions, согласитесь включить workflow.
Нажмите Обновление котировок → Run workflow — первый прогон вручную. Через минуту в репозитории появятся quotes.json и quotes.md.
Пришлите мне ссылку вида:
   https://raw.githubusercontent.com/ВАШ_ЛОГИН/bonds-quotes/main/quotes.json

Дальше я читаю её сам, в любом чате, без вашего участия.

Настройка под себя

Список бумаг — watchlist.txt. Пишите SECID (SU26207RMFS9) или ISIN (RU000A10B487), скрипт понимает оба. Пустой файл = выгрузятся все ОФЗ.

Комиссия брокера — переменная COMMISSION в начале fetch_quotes.py:

Тариф Т-Инвестиций	Значение
Инвестор (0,3%)	0.003
Трейдер (0,05%)	0.0005
Премиум (0,04%)	0.0004

На коротких бумагах комиссия решает: на месячном выпуске 0,3% съедают около 3,5 процентных пункта годовых.

Расписание — блок cron в quotes.yml. Время в UTC, Москва = UTC+3. Текущая настройка */30 7-16 * * 1-5 — каждые 30 минут по будням.

Что в отчёте
Поле	Смысл
price_pct	цена в % от номинала
price_source	откуда взята: LAST — сделка, PREVPRICE — вчерашнее закрытие
cost_per_bond	сколько реально спишется: цена + НКД + комиссия
ytm_gross	эффективная доходность до налога
ytm_net	эффективная доходность после НДФЛ и комиссии
moex_yield	доходность в терминале Мосбиржи — для сверки
days_left	дней до погашения
Ограничения, о которых стоит знать
Расчёт от даты снимка, режим Т+1 не учитывается — на длинных бумагах разница в сотых долях процента, на месячных может быть заметнее.
Налог считается упрощённо: 13% от общей прибыли (купоны плюс погашение минус все затраты). ЛДВ и вычеты ИИС не учитываются — на сроке до трёх лет они и не применяются.
Берётся цена последней сделки. По неликвидным выпускам она может быть нерепрезентативной — перед сделкой всё равно смотрите стакан.
GitHub отключает workflow по расписанию после 60 дней без активности в репозитории. Если пауза затянулась — зайдите в Actions и включите обратно.
Купонные ставки будущих периодов у флоатеров (ОФЗ-ПК) заранее неизвестны, ISS отдаёт нули. Доходность по ним посчитается неверно — их лучше оценивать вручную.
